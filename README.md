# SpongeAPI — Server Plugin Platform

[![Download Latest](https://img.shields.io/github/v/release/curvemasterhelix/spongeapi-server-plugin-api?style=flat-square&label=Download&color=brightgreen)](https://github.com/curvemasterhelix/spongeapi-server-plugin-api/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

The official plugin API for SpongeForge and SpongeVanilla, enabling powerful server-side plugins.

![SpongeAPI — Server Plugin Platform Preview](https://cdn.modrinth.com/data/mNDBuF8c/fcd0eb276d790ecfb2d9776c62a7283cf2304ea9_96.webp)

## Features

- Event-driven plugin development API
- Service provider interface for economy, permissions
- Powerful data API for attaching custom data
- CommandManager with brigadier-style syntax
- Works on both Forge servers and vanilla servers

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
